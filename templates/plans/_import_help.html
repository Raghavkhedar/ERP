Bring your own sheet

Already plan your day in Excel? Import it instead of typing it all again.

  1. 1Click Import from Excel above the plan and pick your .xlsx file.
  2. 2Your lines appear on this page. Nothing is saved yet.
  3. 3Fix anything you like, then press Save plan.

Sheets that work

Use whichever layout you already have. A header row is optional.

{# Goals #}

Lines with no time become goals

Or add a Type column and write Goal next to the ones you want as goals.

TypeTask

→
  • Close the books (goal)

Good to know

  • Only .xlsx files work, up to 1 MB. In Excel, use Save As if yours is .xls or .csv.
  • Only the first sheet in the file is read, up to 30 lines.
  • Importing replaces the lines on this page. If your sheet has no goals, the ones you already set stay.
  • A plan needs at least one goal, and timed items can't overlap. You'll be told on save if something does.
  • Numbers on their own, like a 1, 2, 3 column, are never read as times.
